# 識別子の定義と命名ルール

データの検索性、URLの永続性、およびモデル間の競合を回避するためのルール。

---

## 1. Slug (URL / 車種系統)

車種の「系統」を定義する。

- **形式**: `[maker]-[model]`
- **原則**: カタログ上の名称を使用し、型式や仕様は含めない。
- **例**: `honda-cbr250rr`, `yamaha-fzr750r`

---

## 2. ID (タイムライン内の主キー)

個別の年式やモデルチェンジ単位を唯一無二に特定する。

- **基本形式**: `[maker]-[model]-[model_code]`
- **例**: `honda-vfr750r-rc30`

---

## 3. 特殊ケース・例外ルール

同一車種名で仕様が分かれる場合は、以下の優先順位で識別子を付与する。

### 3.1 世代・型式の区別 (ニダボ等)

同一名称で型式が異なる場合は、必ず型式（model_code）を ID に含めて分離する。

| 対象             | ID                    | 備考     |
| :--------------- | :-------------------- | :------- |
| CBR250RR (4気筒) | `honda-cbr250rr-mc22` | 1990年〜 |
| CBR250RR (2気筒) | `honda-cbr250rr-mc51` | 2017年〜 |

### 3.2 スペック・馬力規制の区別

同一型式内で、馬力規制などによる大幅な仕様変更がある場合。

| 対象            | ID                         |
| :-------------- | :------------------------- |
| MC22 (45ps仕様) | `honda-cbr250rr-mc22-45ps` |
| MC22 (40ps仕様) | `honda-cbr250rr-mc22-40ps` |

### 3.3 装備差 (ABSの有無等)

ABSの有無で併売されている、あるいはデータとして分ける必要がある場合。

| 対象           | ID                             |
| :------------- | :----------------------------- |
| MC51 (標準)    | `honda-cbr250rr-mc51-38ps`     |
| MC51 (ABS仕様) | `honda-cbr250rr-mc51-abs-38ps` |

### 3.4 限定・特別仕様 (SP, SE, 等)

SP仕様やSE仕様など、特定のグレード・特別仕様が存在する場合。

| 対象             | ID                      | 備考                                 |
| :--------------- | :---------------------- | :----------------------------------- |
| NSR250R (SP仕様) | `honda-nsr250r-mc21-sp` | マグネシウムホイール、乾式クラッチ等 |
| NSR250R (SE仕様) | `honda-nsr250r-mc21-se` | 乾式クラッチ、調整式サスペンション等 |

---

## 4. アセットファイル命名

画像等のアセットは、IDと連動させた命名を行う。

- **形式**: `[model_code]-[variant]-[color].png`
- **例**: `mc22-45ps-tricolor.png`, `mc51-abs-38ps-matte-black.png`, `mc21-sp-rothmans.png`
